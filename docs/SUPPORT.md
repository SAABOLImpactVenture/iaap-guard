# Support

## Supported path

The supported distribution is the hosted [IaaP Guard GitHub App](https://github.com/apps/iaap-guard). The public composite Action and local public CLI are retired.

Before requesting help, confirm:

- the App is installed for the repository;
- the pull request changes a supported file type;
- the Check is attached to the current head revision;
- repository and archive sizes remain within [known limits](KNOWN-LIMITS.md); and
- multi-repository membership is reciprocal and accessible when product context is expected.

## Security reports

Use GitHub Private Vulnerability Reporting for suspected vulnerabilities. Never post credentials, tokens, webhook payloads, private repository content, or exploit details in a public issue.

## Product questions

Public issues may be used for documentation, adoption, and product-contract questions that contain no sensitive information. Hosted implementation, cloud deployment, rule execution, and internal test details are not handled in public issues.
