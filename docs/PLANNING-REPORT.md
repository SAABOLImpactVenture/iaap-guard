# Product Improvement Plan

When deterministic findings exist, the hosted IaaP Guard Check may include a bounded improvement plan that maps findings to product outcomes, epics, key results, and suggested follow-on work.

The plan is evidence for accountable planning. It does not create work items, mutate repositories, authorize remediation, approve exceptions, or replace organizational governance.

Public planning document shapes are retained in:

- `schemas/planning-report.schema.json`
- `schemas/product-planning-report.schema.json`

Plan-generation logic and internal regression tests are maintained privately.
