# Changelog

## 1.0.0 — 2026-08-15

First bounded V1 release of IaaP Guard.

### Included

- deterministic context-aware Infrastructure-as-a-Product rule evaluation;
- `scan-result/v1` and transparent `coverage/v1` scoring;
- advisory improvement planning;
- reciprocal multi-repository product assessment;
- immutable PR-base Evidence Continuity;
- deterministic adoption readiness and preflight;
- least-privilege GitHub Action and public GitHub App adapters;
- retained live, operational, clean-adopter, security, and external-adoption evidence;
  and
- frozen V1 compatibility and authority contracts.

### Boundary

This release does not add work management, organizational OKR ingestion, enterprise
strategy, infrastructure execution, customer infrastructure credentials, repository
mutation, automated remediation or authorization, persistent SaaS analytics,
cross-organization V1 federation, Marketplace billing, compliance authority, or
production-readiness claims.
